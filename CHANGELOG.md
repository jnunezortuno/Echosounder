# Historial de cambios

## 1.0.0 — 2026-11-06

- Primera versión estable de la aplicación Python con interfaz de adquisición y visualización.
- Incluye simulador, adquisición serie, visualizaciones de forma de onda, espectro y mapa de profundidad, y exportación CSV.
- Mejora los hints de los controles de adquisición y el diagnóstico del lanzador de Windows.
- Especifica el paquete explícitamente para que la instalación editable incluya el módulo `echosounder`.
- La comunicación con una ecosonda real y las escalas físicas siguen pendientes de validación con el firmware y el hardware.
